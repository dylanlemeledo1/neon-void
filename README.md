# 🚀 NEON VOID — Shooter Spatial

Un shooter spatial complet, style **néon / cyberpunk**, écrit en HTML/Canvas/JavaScript pur.
**Un seul fichier**, aucune dépendance, fonctionne hors-ligne et sur mobile.

## ✨ Fonctionnalités
- Vaisseau du joueur avec déplacements fluides + réacteur animé
- 3 types d'ennemis (grunt, zigzag, tank) + **boss toutes les 5 vagues**
- Vagues infinies avec difficulté croissante
- Power-ups : **W** (arme +), **S** (bouclier), **+** (vie)
- 4 niveaux d'arme (tir simple → tir à 5 projectiles)
- Particules d'explosion, étoiles défilantes, effets néon lumineux
- Sons générés en direct (Web Audio, aucun fichier audio)
- Score + **meilleur score sauvegardé** (localStorage)
- Pause, écrans menu / game over
- **Contrôles tactiles** (glisser pour bouger, tir auto) sur mobile

## 🎮 Contrôles
| Touche | Action |
|--------|--------|
| ← → ↑ ↓ ou ZQSD | Se déplacer |
| Espace | Tirer |
| P | Pause |
| Mobile | Glisser le doigt, tir automatique |

## ▶ Jouer en local
Ouvre simplement `index.html` dans ton navigateur. C'est tout.

Voir les instructions ci-dessous dans la conversation, ou :

2. Pousse ce dossier
